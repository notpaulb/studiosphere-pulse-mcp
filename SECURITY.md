# Security Policy

StudioSphere Pulse is a hosted audio analysis service operated by StudioSphere Inc.
This public repository contains documentation, MCP metadata and a portable plugin
package. It does not contain the private production implementation. The plugin
connects to the live hosted service; it contains no credentials or executable hooks.

Do not include API keys, private audio URLs, customer data, credentials, logs, or payment details in GitHub issues or pull requests.

To report a security issue, contact:

```text
support@studiosphere.space
```

Report suspected vulnerabilities privately with reproduction steps and the affected
plugin version or commit. Redact credentials, private job references and customer
data. Do not perform disruptive tests against production. The package licence does
not grant rights to submitted audio or override each sample's own licence.
